📥 Importa

📥 Importa dati da CSV o Excel

Carica un file CSV o XLSX con le intestazioni nella prima riga. Verrà mostrata un'anteprima prima di confermare.

📥 Importa sezione singola

📋 Template CSV

Scarica un template CSV per ogni sezione: contiene le intestazioni corrette e una riga di esempio.

💡 Suggerimento: apri il template con Excel, compila le righe, salva come CSV e importalo dalla griglia sopra.

📊 Formati accettati

  • CSV — delimitatore ; o , (auto-rilevato)
  • XLSX / XLS — primo foglio del file
  • Intestazioni — la prima riga deve contenere i nomi delle colonne
  • Dimensione max — 200 MB per file
